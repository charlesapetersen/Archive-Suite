`institutional-compute/train_seg.py` `gap_score` (lines 245-283: both the accuracy and the paired difference intervals

`13-stage-rules/12-training-kit.md` §7.5; the routes row `seg-2b-lora-k200`. Classes: noise; a verdict on too little.
The gate passes a candidate when the low end of its paired held-out interval is above −3 points, with at least 267
known gaps behind it. The interval resamples folders, and nothing sets a minimum number of them. W46.kit-continuation's
held-out set is "the next box of that material", and a box is one or a few directories: with one folder every draw is
the same folder and the interval is the point. Measured (hunt, and the refuter independently, each calling `gap_score`
on synthetic sets): a candidate 2.96 points worse on 270 gaps passes with one folder, [−2.96, −2.96], and fails with 30,
[−4.81, −1.11]; at −6.0 on 300 gaps the interval is [−6.0, −6.0] with one folder, [−8, −4] with two, [−12, −3] with
three, [−11.3, 0.0] with twenty. `MIN_KNOWN_GAPS` counts gaps, not folders, and `RUNS_NEEDED = 2` covers rerun wobble
only: both runs get zero-width intervals. The corpus held-out set the shipped kit is checked on has 22 folders (median
93.5 gaps; six alone hold 267 or more), so the shipped build's own check is not affected. The 267 itself came from a
document bootstrap over five boxes, not from this folder bootstrap. The minimum is also above one box: Lincoln box 2,
on which the continuation was measured, has 244 known gaps, so the experiment the owner's call 7 rests on would itself
fail the support floor; note 12 records the support question as decided ("the gate's minimum support applies to it"),
but neither W46.kit-continuation's entry nor the routes row says a user needs a further reviewed or tagged box of at
least 267 known gaps beyond the 200 corrected. The anchor check compares a point difference with the 3.2-point margin:
that is the form call 7.2 decided (`seg-kit-gate.md` line 111), and it stands. Hunt (major, its first finding), refuter
(H1 confirmed, measured), this session (read the code).

**Queue:** W46.kit-gate-groups, offline/$0: the gate's intervals resample documents within the held-out set (or folders
and, inside each, documents) so a one-folder set has a real interval, or the gate refuses below a stated folder count;
the support minimum is derived again on the gate's own resampling unit (`kit_gate.py`'s needed column, `seg-kit-gate.md`
