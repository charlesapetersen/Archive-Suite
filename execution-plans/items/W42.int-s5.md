## What exists before this item (surveyed 2026-11-13)

- Output was page 1 a bare image (no layer), page 2 the text page with the header (`OCR/PDFGenerator.swift`). The SPEC
  already allows a layer on page 1 (`SPEC/tag-format.md` §"2-page PDF structure"), so a layer on the image page of
  image-plus-text needs no SPEC change. A layer-only output (no text page) does: the header needs a carrier first.
- VisionOCRKit's writer and aligner were internal; the app kept no Vision boxes; no deskew, no PDF/A, no ToUnicode, no
  hand placer in Swift (kraken blla + CTC is Python under `scripts/segbench/`). No Vision OCR 1.16.0 size table exists
  in the repo; the baseline has to be made by running the package's own pipeline on the smoke set.

## Plan, by checkpoint

1. **Print layer on the image page** (checkpoint 1): `VisionOCRKit/TextLayer.swift` (public: the engine's Vision lines,
   the aligner, the lab writer); `OCR/TextLayerRule.swift` (print kinds placed, hand and mixed pages text page,
   RTL/CJK/Thai text page, unknown kind placed only when the reading aligns); `PDFGenerator.generateOutput` returns the
   layer's outcome; two main-actor regenerations moved off the main actor; `scripts/test-text-layer.sh`.
2. **Straighten** (`straightenReadingCopy`): median Vision line angle >= 1 degree → the image page is the deskewed copy
   on an enlarged canvas (nothing cropped), the layer read on it; empty `SettingsSheetModel.switchPending` of it.
3. **Run report**: each page's layer outcome recorded on the job and shown (which pages got the text page, why).
4. **PDF/A-2b and complete ToUnicode maps** (XMP `pdfaid`, sRGB output intent; veraPDF 1.30 at /opt/homebrew/bin).
5. **Output form setting per input format and kind** (image-plus-text with or without the layer; layer-only after the
   header carrier, a SPEC change: Tier-2, both apps).
6. **Hand placer** (kraken blla + McCATMuS CTC, 0.67 gate, `reflows` readers to the text page) — a Python runtime and
   model downloads in the app; likely its own item. Until it lands `placeHandOnImage` stays in `switchPending`.
7. **Smoke-set measure**: each combination read back through PDFKit, sizes against Vision OCR 1.16.0's, with UIUC
   00156, 00233, 00149 among the pages.
