# W40.reader-tiled-pages

Implemented All Pages Tiled in the document View menu and toolbar, with lazy physical-PDF-page tiles,
click-to-read, safe pane command gating, and window tabbing disabled. Serial private-document thumbnail
renders keep PDFKit off the main executor and never write to the source. Opening a tile forces the PDF
source for that page while leaving the saved JPEG preference alone.

were exported from xcresult and inspected. Final Reader smoke passed (731 tests, 3 skipped, zero failures), including the JPEG regression.
