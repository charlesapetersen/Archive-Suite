# W42.int-s5-searchable — progress notes (claimant only)

## Checkpoint 1 (2026-11-13): the carrier, the form, its rule

Landed: the header's carrier is the XMP (`archivesuite:pageHeaders`, Core `PDFHeaderCarrier`, `PDFPageRole`;
SPEC/tag-format.md §"The searchable form"). Why XMP: Quartz's PDF/A writer drops any XMP added with
`addDocumentMetadata` (measured: kept without PDF/A, replaced with it), so `ArchivalFinish` splices the list into the
XMP it already rewrites unfiltered; PDF/A-2 wants Info entries mirrored in XMP anyway; the header is per page.
`PDFGenerator.generateOutput(sourceFormat:)` writes the searchable form when `searchableFor` (new `.strings` setting,
`format/kind` pairs, default empty) picks it: placed on Vision's lines where the reading aligns, else route `unplaced`
(the reading's lines down the image); no reading / RTL / CJK / placeholder → a pair, `Output.formFallback` says why.
Run log: "Pages set to be one searchable page, with no text page". Merges mix the forms. Date evidence rewrites the
carried header. Improve OCR refuses (`ReOCRPairs.Refusal.searchable`). Tests: `scripts/test-text-layer.sh` section 7
(27 checks; veraPDF 2b passes the searchable, unplaced, dated and mixed-merge files), Core `PDFHeaderCarrierTests`.
