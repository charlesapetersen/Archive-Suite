# W46.layout-partition-score — session notes

## Predeclared protocol (written 2026-11-17, before any reading)

**Question.** Does the shipped newspaper partition (`NewspaperPagePlan.prepare`: every label kept, redundant
crops omitted, earlier crops and moved lines whitened, a masked whole-page fill read last) read L9 as well as
(a) the whole page and (b) the measured raw-region baseline (W46.ocr-regions' PP arm: pictures dropped, a region
90% inside a larger one dropped, unmasked crops, the detector's order, no fill)?

**Inputs.** The 15 frozen L9 originals (sha256-checked). The app's own plan images, written by the Debug Processor
(`NEWSPAPER_PLAN_DUMP`, `scripts/segbench/layout_partition_plans.sh`) with the real detector. The raw-region control
is cut from the same originals with the app's `pixelBox` geometry from the same detection, so only the partition
differs.

**Reader.** PaddleOCR-VL 1.6 4-bit, the app's shipped Mac model (`mlx-community/PaddleOCR-VL-1.6-4bit`, Vision OCR's
installed snapshot), prompt `OCR:`, temperature 0, through the app's runtime python and `read-model.py`'s generation
loop with the model loaded once. Every image (whole page, crop, fill) is shrunk to a 2,048 px longest side, the
Processor's page-reader ceiling (`ImageEncoding.maxOCRDimension`). Token caps: 8,192 for a whole-page-sized image
(whole page and fill), 4,096 for a crop (the cluster baseline's convention); 540 s a request. Fresh controls are read
here; the Sherlock replies are not reused (different runtime, quantisation and image size).

**Scores.** Strict NES in reading order (`ocr_panel_score.score`, stratum L9), NewsBench's order-free bag-of-words F1
and order gap (`ocr_scorers.newsbench`), missed and added words per 100 truth words (added = duplication or invention),
pages with an empty/failed or capped request, total seconds a page and request count.

**Comparisons.** Primary: shipped partition minus raw regions, and shipped partition minus whole, paired over the 15
pages, 95% page bootstrap (`paired`, 10,000 rounds, seed 0); an interval crossing 0, or a gap under the 0.49-point
floor, is a tie. Secondary, descriptive: the fill's own share of the words (the partition without its fill, scored
the same way), to separate the fill from the masking.

**Stops.** Pilot one page through all three arms first. Stop and report, rather than expanding, if: the pilot's
projected total is over 4 hours of reading; the reader fails (error, not a cap) on more than 3 of 15 pages in any
arm; the plans dump disagrees with the app's own region count on any page; memory pressure trips the heavy lock.
Expand to a second reader only if this arm leaves the shipped partition's sign unresolved against both controls
(both ties with intervals wider than 10 points); a $0 open reader only.

**What the answer can change.** A partition beyond the interval below raw regions on content (order-free) is a
defect in the shipped stage, filed as a follow-up; a tie or better supports the shipped design for this reader. The
owner's detector and all-reader choice is not reopened by this arm alone.
