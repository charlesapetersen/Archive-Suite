# W46.kit-continuation-replay — notes

## Size-and-necessity review (before the hand-over, owner rule 2026-10-22)

1. **The question, and what it can change.** The kit's continuation (`kit_continuation.py rows`) has one measured
   recipe: box 1's k = 200 corrections plus three windows of the corpus 2B's own training set for each
   (W46.seg-adapt-lora: Lincoln box 2's errors 17.2 to 4.9 per 100 gaps). No kit user but the owner has that set. The
   answer sets `rows`' default (`--no-replay`, or a public replay) and the README's advice in §"The continuation".
   Today a kit user runs an unmeasured recipe.
2. **Why results in hand do not settle it.** Only k = 50 and k = 200 with corpus replay were trained. Nothing shows
   whether the replay is what kept k = 200 from forgetting, or whether a public set (unlike Lincoln) does as well or
   does harm.
3. **Size.** Six jobs: stage and merge on CPU; four on one GPU each: train `none` (62 windows), score it, train
   `public` (248 windows), score it. The base and k = 200 answers are home and are reused, so neither arm is rerun.
   Measured on the same pipeline (W46.seg-adapt-lora, Sherlock 2026-11-05): training 15 minutes for about 62
   windows and 54 for 248, scoring under 5 minutes, so about **1.35 GPU-hours**. The time limits add up to a
   ceiling of 3.75. Nothing smaller answers it: these are the two arms, at k = 200 only (k = 50 already bought
   little), with one training each; the scoring set is the frozen 175 windows the base and k = 200 answered. No
   calls, $0.
4. **Verdict: useful now.** It changes a kit default that every non-owner user of the continuation runs.

## The arms (fixed before any run: `seg_adapt_replay.py` docstring)

- `none`: the 62 k = 200 correction rows alone, byte for byte W46.seg-adapt-lora's `corrections/k200.jsonl`.
- `public`: the same plus 186 TABME++ windows (W46.seg-tabme's frozen fs-seg-2b requests, with page text). Each target
  is the shipped 2B's own reply from that run (`runs/2b-it`, 2,079 of 2,080 answered) with every boundary set to
  TABME++'s truth. That is the rows' own construction, and a kit user has every part of it. The 2B was wrong on 154
  of the 1,113 replayed gaps, so these rows also teach it TABME++. The draw is seeded (41); 1,237 public pages.
- **Not measured: the material's own accepted windows.** On Lincoln, box 1 holds 22 windows outside its first 200
  gaps. They are also box 1's held-out set, and 186 are needed. A kit user's own unreviewed boxes, with the 2B's
  calls as targets, are a later arm if `none` and `public` both fall short.
- The decision rule (docstring): the cheapest arm whose box-2 change against k = 200 has its interval's high end below +3
  errors per 100 gaps, and that loses no more catalogue starts on box 2 than k = 200.
