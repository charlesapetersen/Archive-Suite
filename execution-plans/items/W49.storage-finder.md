## Remaining sub-steps

1. **Reader discovery in tags mode.** A root without File ▸ Use Catalogue Companions lists only Read/Unread-tagged
   PDFs (`CorpusWalker.tracksReadState`), so untagged new output is invisible there until catalogue mode is turned on.
   Decide the engineering route (e.g. offer catalogue mode when a tags-mode scan sees companions, or admit
   companion-bearing PDFs read-only) and verify it off-screen in the VM.
2. **Reader projection when mirroring is on.** A per-archive Reader preference (beside the catalogue-mode key), off
   by default. When on, a catalogue edit projects the facts' tag vocabulary through `CoordinatedTagWriter` and
   records exactly what the suite wrote (an ownership ledger per occurrence).
3. **Divergence (2b).** With mirroring on, detect a mirrored tag changed in Finder and offer Import (take the Finder
   value into the record as a user edit) or Re-publish (write the record's value back); never adopt it silently.
4. **Remove suite tags (3b).** On turning mirroring off, offer an undoable removal of only ledger-owned tags; hand-made
   tags and tags the suite cannot prove it wrote stay.
5. Improve OCR: its flagged-files finder reads only Finder tags (`ReOCRFlaggedFinder`, `ReOCRJob.isFlagged`), so an
   adopted or new file whose OCR Poor lives only in its companion is not found; read the record in an adopted root.
   Clear and reflag touch only tags already present, so they never tag a clean PDF.
