## What is left (from the W49.storage-finder sessions)

1. A folder that holds tagged legacy PDFs and untagged catalogue output lists the tagged ones and gives no notice
   (the empty-list offer shipped). Decide whether a notice is needed there; adoption is the main route.
2. **Reader projection when mirroring is on.** A per-archive Reader preference (beside the catalogue-mode key), off
   by default. When on, a catalogue edit projects the facts' tag vocabulary through `CoordinatedTagWriter` and
   records exactly what the suite wrote (an ownership ledger per occurrence).
3. **Divergence (2b).** With mirroring on, detect a mirrored tag changed in Finder and offer Import (take the Finder
   value into the record as a user edit) or Re-publish (write the record's value back); never adopt it silently.
4. **Remove suite tags (3b).** On turning mirroring off, offer an undoable removal of only ledger-owned tags; hand-made
   tags and tags the suite cannot prove it wrote stay.
5. Ownership record design choice: keep "what the suite wrote" in the companion (travels with the pair, shared by
   both apps; a catalogue SPEC change) or in each app's local state (does not travel; the Processor's own writes
   would need one too). The Processor today writes mirrored tags with no ownership record, so Remove Suite Tags
   cannot yet prove what it wrote: tags a mirrored run wrote before this item lands need the reviewed reconciliation
   §7 of the design describes, not guessed ownership.
6. The switch: today only the Processor's general setting. §7 asks for the archive's intent with its root settings
   so the apps agree; the Reader's catalogue mode is a per-root local preference beside which a mirror flag could sit.
