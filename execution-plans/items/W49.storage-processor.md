# W49.storage-processor

The shared XMP identity codec reads the exact open PDF descriptor. Scratch filing fixtures use
that codec for both initial publication and recovery. Both PDF generators and the merge writer
accept an explicit catalogue identity. Live Capture supplies it when staging a new segment.
Keep existing header rewrites on working PDFs or replace them with catalogue field updates before
publication.

Live Capture uses a single document owner for split segments. Finish saves each exact initial record,
operation UUID, final path and physical destination proof before copying a PDF. Repeated Finish
uses those saved numbers. Each pair and the filed-group ledger must succeed before source
retirement. The existing placeholder-image rule still keeps the affected originals. Legacy staged
derivatives with saved readings and source photos can be rebuilt before filing.

The pre-OCR copy writer prepares a separate derivative. It adds the identity to the existing XMP,
checks the active PDF object graph and rendered pages, and leaves the source bytes intact. The
pre-OCR Process Files route copies regular source files to private working storage, reads those exact
bytes, and saves its filing plan before publishing the pairs. Companion-name collisions reserve
a different name, and source symlinks are refused. Interrupted prepared filing is local and key-free.

Process Files now routes fresh, rebuilt PDF, mixed, batch, standard resume and row retries
through private working storage. After segmentation and merge it reserves final destinations and
freezes the identities, initial companions and exact upstream journal digests. It keeps those
upstream journals through verification. A row retry after filing creates a new verified pair
alongside the earlier output. Catalogue recovery resumes a frozen plan without OCR credentials.

Scratch Process Files runs use local Apple Vision to check separate and merged outputs, shared
document ownership, source-page roles and post-run retry. Follow through with full integration
proof for cached resume, the batch completion route, mixed PDF handoff and interrupted filing.
Optional segment JSON stays an export. Improve OCR and restore remain the separate rerun item.
