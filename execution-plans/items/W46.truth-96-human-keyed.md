## Built (2026-11-27)

1. **Transcription rules (`ArchiveProcessor/scripts/segbench/human_truth_rules.md`):**
   - Derived directly from `ocr_truth.py` (`PROMPT`, `words()`, `STRUCK`) and `ocr_panel_score.py` (`normal()`, `tokens()`, `score()`, `STRATA['S0']`).
   - Covers reading order, original spelling/case/punctuation, line breaks and S0 hyphenation, `[illegible]`, struck/inserted text, tables as `" | "` cells, what the scorer already normalises (curly quotes, dashes, NFKC, whitespace, table bars, bullets), and four worked examples (typewritten, printed, handwritten, mixed) on invented pages only.
2. **Blind keying, compare/dispute, versioned settle, and replay-verified rescore (`ArchiveProcessor/scripts/segbench/ocr_truth_human.py`):**
   - `init-work`: indexes page images into a keying workspace without touching or copying any text/drafts.
   - `serve-keying` & `build-keying` / `import-keying`: blind keying UI (one zoomable, rotatable page image + transcription textarea + kind/table-form controls + optional note + collapsible transcription rules; **no model reading or other reader's text anywhere**). Saves atomically to per-reader, per-page files (`<work>/keyings/<reader>/<page>.json`), resumes across sittings, and accumulates active per-page seconds (pauses on idle/hidden tab).
   - `compare`: aligns Reader A and Reader B word-by-word via `ocr_truth.words` + `ocr_truth.spans`, computes pre-settling inter-reader agreement and measured words/minute overall and by kind (replacing the assumed 25/10 wpm rates), and emits a third-person dispute sheet (`<work>/dispute/index.html`) following `CLAUDE.md` owner-sheet rules (notes under `_notes`, unasked fields listed, upright rotate button, optional span boxes, active settling timer `_settling_seconds`).
   - `settle`: writes settled human truth into a **new versioned directory** (`truth-<version>/`, never overwriting `truth/` or `pages.tsv`, refusing reserved or existing targets) along with `pages.tsv` and `metadata.json` (agreement-by-kind, measured wpm, settling time).
   - `rescore`: replays `ocr_rescore.score_set` on the current drafted truth first and aborts if any route's NES deviates from `segbench-results/ocr-scorers.json`, then rescores all saved 96-page readings on `truth-<version>/` (`$0`, no model calls) and reports Gemini & Claude NES movements first, flagging any ranking change as **reported (no decision)** for the owner.
3. **Tests (`ArchiveProcessor/scripts/segbench/test_ocr_truth_human.py`):**
   - Invented-page tests covering: live HTTP blind keying server (zero model text, atomic per-reader per-page save, multi-sitting resume, elapsed-time accumulation, `node --check` on inline JS), offline bundle import, two-reader word-by-word compare & dispute sheet (`node --check`), non-overwriting versioned settle + reserved-name refusal, and replay-failure guard + human-truth rescore ranking-change report.
