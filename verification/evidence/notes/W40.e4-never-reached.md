## Most notable findings

1. **Four dead functions.** `NotesNavigationModel.currentUserFilter` (NotesNavigationModel.swift:517) and `FormattingContext.canAutoFillFromZotero` (EditorFormatting.swift:91) have no caller anywhere. The convenience `NotesIndexer.init()` (NotesIndexer.swift:75, "retained for isolated use") has none either. `ZoteroCacheStore.removeAll` (ZoteroCacheStore.swift:51) belongs to a type nothing in production builds; the rest of its functions ran only because `ZoteroClientTests` calls them, so the whole type is test-only. `ZoteroClient` has a `metaCacheKey` (ZoteroClient.swift:555) and never uses the store, so a Zotero cache looks planned and unwired.
2. **The window-launch and delegate rows from the first pass are gone.** `NotesWindowAccessor`, `PanelDividerHandle`, `tableViewSelectionDidChange`, `textViewDidChangeSelection` and `FormattingToolbar.body` are no longer listed, so the first pass's worry that UI-process coverage was missing does not hold. `ThumbnailImageCache` and the quit/close alerts are gone too.
3. **Store folder and library opening: 16 rows, probably reached by the test that did not run.** The panel, alert and relaunch wrappers in `StoreFolderChooser.swift:303-407` and `ReaderRootChooser.swift:121-133`, plus `LibraryActions.newLibrary/open/openRecent` and `openLibraryFromFinder`. Re-run `ChooseStoreFolderUITests` before treating these as gaps. `handleOpenDocuments` and `deliverPendingLibrary` (ArchiveNotesApp.swift:157, 176; Finder-open) are the exception: no test names them.
4. **Menu trampolines that no run chose from a menu (about 18 rows).** Seven `FormattingContext` format toggles (EditorFormatting.swift:120-180, ledger N-12), six column-header menu actions (NotesTableView.swift:765-795, N-08/N-09), and the model setters `setDateUncertain`, `setDisplayCalendar`, `setSentWith`, `setSentWithUncertain` (NotesNavigationModel.swift:340-355, N-19/N-20/N-23). Unit tests exercise the layer below each of these.
5. **Image drop and the stray-image pick bar (7 rows, N-15).** `EditorTextView.performDragOperation`, `isImageURL`, `tiffToPNG`, `ensurePNG` (EditorTextView.swift:1202-1327) and `NoteEditorPane.pickImageBar`, `pickStrayImage`, `chooseImageFile` (NoteEditorPane.swift:643-681).
6. **Chip menu actions for Zotero (6 rows, N-43)** and **Advanced Search save and commit (9 rows, N-33)** (`saveAsSmartFolder` NotesAdvancedSearchSheet.swift:124, `commit` :114, the filter bar's date popover). Export and Print failure paths (6 rows) have no ledger row.
7. **10 unreachable:** 9 are DEBUG-only (insertTestBlock, three accessibility probes' `isAccessibilityElement`, two `uiTest` markdown seams, `attributedForTest`, `isHarnessLaunch`, `isGeneratedNotesFixture`); `PanelDividerView.init(coder:)` (PanelDivider.swift:85) is a fatalError stub.
