## What was asked

Four `ArchiveNotes/KNOWN_ISSUES.md` follow-up entries (W7-S1a, S2, S3, S4, July 2026) listed live checks that were
never run because GUI work was paused and Notes had no scratch-store launch override. The checks were first mapped
to the existing UITests; the ones no test drove were written as `NotesW7ChecksUITests` and run in the VM.
