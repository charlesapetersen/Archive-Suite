# Independent verification of S-019 and S-009

Codex (gpt-6.2-sol) checked baseline `7252c39b` on 2026-11-21. Claude Opus 5.5 recorded the
initial reproductions in `0f82bef9`. This session drove the app in the headless Tart VM using
the generated Notes scratch library. Both focused XCUITests passed.

## S-019 · A typed closer can erase prose on the first save

Seed the fixture's Reader-linked note with a body ending in an unclosed block header:

```markdown
<!-- block: reader-doc
     link: archivereader://reveal?root=c07b0700-2000-4000-8000-000000000002&rel=sample.pdf
```

Open it in the styled editor. Put the caret at the end, press Return, type
`TRANSECT OBSERVATION`, press Return, and type `A --> after-closing-marker`. The editor showed
both text markers. After autosave, the note's Markdown had already lost `TRANSECT OBSERVATION`:

```markdown
<!-- block: reader-doc
     link: archivereader://reveal?root=c07b0700-2000-4000-8000-000000000002&rel=sample.pdf -->
 after-closing-marker
```

Select another note and reopen the edited note. The editor showed a source chip and
`after-closing-marker`, with the prose still absent. `NoteStore.saveBody` parses the edited body
on the first save. `BlockParser.parseSegment` takes the typed closer as the end of the header,
and `parseHeader` skips the colon-free prose. The fix is queued as W49.fix-notes-unclosed-header.
Keep `NotesTextLossSuspectTests.s019TypedCloserAfterUnclosedHeader` as the regression.

## S-009 · Raw Markdown paste saves an orphan PNG and U+FFFC

Open My First Note in the VM and click the raw Markdown toggle. Confirm that the literal
`**bold**` appears. Position the caret at the end, seed an 8×8 PNG on the guest clipboard
and click G4's `an.editor.test.pasteImage` seam. It runs the production image-paste handler and
flushes the editor. The seam reported success targeting the selected note. A new
`assets/pasted-20261121-155508-816-703e.png` matched the seeded bytes. The saved Markdown had no
reference to that filename and ended with exactly one U+FFFC object replacement character.

`EditorTextView.tryPasteImage` inserts an attachment, and
`MarkdownEditorView.Coordinator.currentSerialization` saves the raw text view's string.
This run exercised paste. Image drop shares the handler. The fix is queued as
W49.fix-notes-raw-image-paste. Keep `NotesTextLossSuspectTests.s009RawModeImagePaste` as the regression.
