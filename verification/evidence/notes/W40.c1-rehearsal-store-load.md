- **Date / commit:** 2026-10-14, at `6d7aa5c1` (origin/main when the run was made) plus the W40.c1 scripts.
- **Set:** `~/Library/Caches/ArchiveSuiteRehearsal/notes-store/` built by
  `python3 ArchiveNotes/scripts/make-notes-rehearsal.py` (defaults: `--items 400 --seed 40`); its `MANIFEST.txt`
  carries the counts and `hazards.tsv` the deliberately unusual items.
- **How:** a throwaway XCTest in the app-hosted `ArchiveNotesTests` bundle (Debug app, host, unit lane, nothing drawn;

  `xcodebuild test -project ArchiveNotes.xcodeproj -scheme ArchiveNotesUnit -destination 'platform=macOS'
  -derivedDataPath ./build/DD -only-testing:ArchiveNotesTests/RehearsalStoreProbe`.

## Found: an unclosed block header gains a line on every save

The six `ROUNDTRIP-DIFF` items are exactly the six notes the generator gave an unclosed
`<!-- block: reader-page` header (no `-->`). In every one, each encode added one block. A second throwaway test
reduced it to a nine-line note, decoded and encoded three times in a row:

```
Intro paragraph.

<!-- block: reader-page
     link: broken header with no close

Tail paragraph.
```

becomes, after save 1, 2 and 3:

```
Intro paragraph.

<!-- block: freeform -->
<!-- block: freeform -->
<!-- block: freeform -->
<!-- block: reader-page
     link: broken header with no close

Tail paragraph.
```

Each `decode` → `encode` inserts one more `<!-- block: freeform -->` line ahead of the unclosed header, and the
block count grows by one each time (`["freeform"]` → `["freeform","freeform"]` → …). No text is lost; it grows
by one line per save, without end. Filed as `W40.fix-notes-unclosed-header` (S3).
