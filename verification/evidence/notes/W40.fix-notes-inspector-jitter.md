# W40.fix-notes-inspector-jitter — before and after (VM, 2026-10-17)

The fix: the detail pane's header and inspectors follow the note the editor holds until the editor has finished
switching (`NotesNavigationModel.detailItemID`), so they change in the same committed pass as the body.

## The recorder's link rule (`an.detail.header+an.editor.text`)

`TransientStateUITests`, one VM run each, the same fixture.

| transition | before the fix | after |
|---|---|---|
| next note (click) | apart: header new, editor old | clean |
| next note (down arrow) | apart | clean |
| previous note (up arrow) | apart | clean |
| switch to an empty folder (Inbox) | apart: header gone, editor still the old body | clean |
| every other transition | clean | clean |

Before: 4 failures. After: 0 failures. The only findings left were the intermittent known issues
`W40.fix-notes-editor-frame-jump` and `W40.fix-split-animation-wobble`.
