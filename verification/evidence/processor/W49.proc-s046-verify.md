## Source and intended behavior

`OCRView` reads and passes the saved setting with Collection ID. In `OCRProcessor.startProcessing` and
`OCRProcessor.performPreOCRedProcessing`, the whole-run review is chosen by the segmentation plan and tagging or
Collection ID. Both pass `false` to the later `performCollectionSegmentation` call. On ordinary and batch
Resume, that call passes the stored preference. `performDocumentSegmentationReview` can then open a review for
each collection after tagging and excludes pages already classified as box or folder labels.

Commit `a6da4e62` explicitly replaced the fresh per-collection review with a whole-run review so users' edits
precede tagging. The current README describes that whole-run review. The switch help describes the
pre-tagging review as something the setting controls. The choice is whether fresh runs should keep their normal
review and the switch should describe only the extra pass on Resume, or whether the switch should control
the normal pre-tagging review with its default on, so users can explicitly skip that review. Simply forwarding
the setting to the later fresh collection stage would open another review after tagging.
